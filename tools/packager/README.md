# 🧩 FlaskKernel

**基于 Flask 的插件化内核项目，专为插件打包与运行设计。**

---

## ⚠️ 环境配置（必看）

本项目**不提供独立的虚拟环境**。  
由于插件打包必须与内核保持绝对一致，请将内核或插件的 Python 环境**完整复制到本项目目录下**，否则无法正常使用！

**操作步骤：**
1. 找到你原本的内核/插件 Python 环境文件夹（例如 `.venv` 或 `venv`）。
2. 将该环境文件夹直接**复制或移动**到本项目根目录（`FlaskKernel/tools/packager/runtime`）下。
